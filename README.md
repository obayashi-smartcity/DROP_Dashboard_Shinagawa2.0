# DROP_Dashboard_Shinagawa2.0 — 投稿づくりチャット DROP. Coach（品川 V2）

CULTURE SNACK（コクヨ × 大林組）で、参加者が DROP に投稿する文を、チャットで一緒につくるツールと、その記録を分析する画面です。
V1（DROP_Dashboard_Shinagawa1.0）とは GAS・プロンプト・記録シートをすべて分けています（V1 には一切影響しません）。

## 中身

| ファイル | 役割 | 版 |
|---|---|---|
| `drop_coach_with_sample.html` | 参加者が使うチャット。GitHub Pages で公開 | chat-v3.0 |
| `drop_coach_dashboard.html` | 運営用の分析画面（管理者パスワードで記録を読み込む／CSV 読み込み／デモ） | dashboard v1.0 |
| `gas/DROP_COACH_GPT.gs` | 仕上げ用 GAS（ログイン・ヒント・投稿文。Azure OpenAI を呼ぶ） | v9 |
| `gas/DROP_COACH_LOG.gs` | 記録用 GAS（ログイン・記録・分析画面への読み出し） | v7 |
| `prompt/drop_coach_chat.md` | 投稿文をつくる AI への指示（GAS が GitHub から読む） | v9 |
| `prompt/drop_coach_hint.md` | ひとことの直後に裏で呼ぶ AI への指示（同じフォルダから自動で読む） | v9 |
| `json/sample_drop.json`・`json/sample_img/` | 見本投稿 8 例（運営作成・架空）。画面の「ほかの人の例」と AI の参考に使う | — |

画面 v3・GAS v9／v7・プロンプト v9 はそろえて使ってください（記録の形が v3 で変わっています）。

## しくみ

```
参加者のスマホ ── drop_coach_with_sample.html（GitHub Pages）
   │ ① ログイン（名前・パスワード。端末に 1 回だけ）
   │ ② ひとことの直後：hint（裏で 1 回・待たせない）  ┐
   │ ③ 最後：coach（投稿文を 1 回）                    ├─▶ DROP_COACH_GPT（GAS）─▶ Azure OpenAI
   │                                                    ┘        └ prompt/*.md を GitHub から読む（5 分キャッシュ）
   │ ④ 記録（投稿文ができた・コピーした・途中でやめた） ─▶ DROP_COACH_LOG（GAS）─▶ スプレッドシート LOG_DROP_COACH の chat_v3 シート
運営のパソコン ── drop_coach_dashboard.html ─▶ DROP_COACH_LOG（export・管理者パスワードのみ）
```

## チャットの流れ（v3）

1. ログイン（この端末で 1 回だけ。答えの使い道を一言添える）
2. 写真をえらぶ（写真なしでも可）
3. **ひとこと**（必須・とばせない）… 投稿文のもと。キーボードのマイクで話して入力も可
   - 画面がひとことを読み取り（気持ち・人・話題）、返事をしてから次へ（例「『コーヒーおいしかった』、いいですね！」）
   - 裏で AI のヒントを呼ぶ（話題・写真から見える「どこが」の候補）
4. **だれと**（ひとことに人が出ていれば先に選んでおく。「どんな人？」は任意）
5. **どこが**（「コーヒーの、どこがおいしかったですか？」のように、ひとことの話題と気持ちで問いを作る。AI の候補は「写真から」として出る）
6. **気持ち**（ひとことに書かれた気持ちは先に選んでおく。選んだ順を記録）
7. **このあと**（2 つまで＋自由記述）
8. あなたについて（端末ごとに 1 回）
9. 投稿文：「AI が整えた文／自分の言葉の文」を切り替え・直せる。ハッシュタグは付けない設定から始まる → コピーして DROP へ

- 上部の「あなたの投稿」バーで、答えるたびに投稿が育つのが見える。押すと「入っているもの」と「ほかの人の例（見本）」
- 見本はひとことを書いたあとにだけ開ける（最初の言葉が見本に引きずられないように）
- ひとことを書いたあとは、いつでも「ここまでで投稿文をつくる」
- メニュー：文字を大きく／ほかの人の例／このチャットについて／最初からやり直す／「あなたについて」を答え直す／ログアウト
- URL に `?staff=1` を付けると、分析用の記録（ノード・ソフト分類・JSON）と、その端末の記録の CSV 保存が出る（運営の確認用）

## 設定

### GAS のスクリプトプロパティ

**DROP_COACH_GPT（仕上げ用）**

| キー | 値 |
|---|---|
| `APP_PASSWORD` | 参加者に配るパスワード（LOG と同じ値） |
| `AZURE_API_KEY_LUNA` | Azure OpenAI の API キー（**リポジトリには絶対に書かない**） |
| `PROMPT_URL_CHAT` | `https://raw.githubusercontent.com/obayashi-smartcity/DROP_Dashboard_Shinagawa2.0/main/prompt/drop_coach_chat.md` |
| 任意 | `DAILY_LIMIT`（400）・`PROMPT_CACHE_SEC`（300）・`PROMPT_URL_HINT`（未設定なら同じフォルダの drop_coach_hint.md）ほか。GAS の先頭のコメント参照 |

**DROP_COACH_LOG（記録用）**

| キー | 値 |
|---|---|
| `APP_PASSWORD` | 参加者に配るパスワード（GPT と同じ値） |
| `ADMIN_PASSWORD` | 分析画面用の管理者パスワード（**APP_PASSWORD とは別の値**。これでログインしたときだけ記録を読み出せる） |
| `LOG_SHEET_ID` | V2 のスプレッドシート LOG_DROP_COACH の ID（**V1 のシートの ID にしない**） |
| `LOG_SHEET_NAME` | `chat_v3` |

### 画面の設定（`drop_coach_with_sample.html` の `CONFIG`）

| キー | 既定 | 内容 |
|---|---|---|
| `GAS_URL`・`LOG_URL` | 設定済み | 2 つの GAS の /exec URL |
| `ASK_SCORE` | false | 体験の点数（10 点満点）を聞く。既定は聞かず、選んだ気持ちから「気持ちの向き」を計算 |
| `HASHTAGS_ON` | false | ハッシュタグを最初から付ける |
| `HINT_ON` | true | ひとことの直後に裏で AI ヒントを呼ぶ |
| `SHUFFLE` | true | 選択肢の並びをシャッフル（並びは記録する） |
| `DROP_URL` | 空 | 入れるとコピー後に「DROP を開く」ボタンを出す |
| `ALLOW_NO_LOGIN` | false | true で「ログインせずに使う（AI・記録なし）」を出す（全員分を記録する方針のため false） |

選択肢の言葉・ソフト分類の重み・気持ちの向き（`V` の `w`・`val`）は仮の値です。記録には選んだものと順番が残るので、重みを変えてあとから計算し直せます。

## 更新の手順（v2.x → v3）

1. このフォルダを GitHub（main）に push する（GitHub Pages とプロンプトが新しくなる。反映まで最大 10 分ほど：GitHub の配信 5 分＋GAS のキャッシュ 5 分）
2. **DROP_COACH_GPT**：`gas/DROP_COACH_GPT.gs` を貼り替え → `checkSetup` → `testHint` → `testChat` を実行 → デプロイを管理 → 編集 → 新しいバージョン（URL は変わらない）
3. **DROP_COACH_LOG**：`gas/DROP_COACH_LOG.gs` を貼り替え → スクリプトプロパティで `LOG_SHEET_NAME` を `chat_v3` に、`ADMIN_PASSWORD` を追加 → `setupTest` を実行（chat_v3 シートと見出し 54 列ができる）→ 新しいバージョン
4. 確認：`LOG_URL?diag=1` をブラウザで開く（`sheet_ok`・`admin_password_set` が true）→ チャットで 1 回投稿 → 分析画面に管理者パスワードでログインして 1 件出ること

v2 の記録（`coach_chat_v2` などのシート）は消さずに残ります。v3 からは `chat_v3` シートに書きます。

## 見本投稿を変えるとき

`json/sample_drop.json` と `json/sample_img/` を差し替えます。HTML の中の `<script id="sampleFallback">` には同じ JSON の控えが入っています（`file://` で直接開いたときだけ使う）。GitHub Pages では json を読むので、控えを更新しなくても動きます。

## 記録（chat_v3 シートの列）

1 回のチャットで「投稿文ができた（完了）」「コピーした（コピー）」「途中でやめた（途中離脱）」「やり直した（やり直し）」のときに 1 行ずつ書きます。同じセッション ID の行が複数あるときは、分析画面がいちばん新しい行を使います。

| まとまり | 列 |
|---|---|
| いつ・だれ | タイムスタンプ／Name／セッションID／終了／開始／所要秒／回答数／最後の問い／写真 |
| ひとこと | 最初のひとこと／ひとことから読み取れたもの（画面の辞書）／話題（AI ヒント → 画面の読み取り） |
| 答え | だれと／どんな人／どこが／どこがの選び方（選択肢・AI候補・自分で）／気持ち（選んだ順）／気持ちの向き（-1〜1）／このあと／属性／体験の点数（ASK_SCORE のときだけ） |
| 分析用 | ノード（共起用：`人:…`・`コンテンツ:…`・`空間:…`・`感情:…`・`意向:…`）／ソフト①挑戦・②属性横断・③心理的安全性・愛着（答えから計算・合計 1） |
| 投稿文 | 組み立て文面（自分の言葉の文）／AI文面／最終文面／採用（AI・自分の言葉）／手で編集／コーチ関与（ひとことのみ・選択あり・AI仕上げ）／ハッシュタグ |
| AI の読み取り | AI分類／AIソフト／AI感情の向き／AI行動／AIコンテンツ／AI空間／AI 5W1H／AI評価／AIひとこと／写真と本文／AI注意 |
| 使われ方 | ヒント状態（秒）／ほかの人の例を見た（回数・どこで）／投稿イメージを開いた／表示順（シャッフルの結果）／問いごとの秒 |
| 版 | AIモデル／プロンプト版／AI秒／アプリ版／記録JSON（画面が送った記録そのもの） |

## 分析画面（`drop_coach_dashboard.html`）

- 読み込み：①記録用 GAS から（管理者パスワード）②スプレッドシートの CSV ③デモデータ（架空・見え方の確認用）
- 見られるもの：全体の数字／到達・問いごとの回答率・時間・途中でやめた場所・時間帯／気持ちのランキングと向き（AI の読み取りとの一致）／だれと・どこが・このあと・話題・材料の数・属性／共起ネットワーク（押したノードとよくいっしょに出るものと「出やすさ」）／KPI ソフト分類（本人の答え vs AI）と一致率／コーチの関与・「ほかの人の例」を見たかでの比較／投稿一覧（検索・詳細）
- 絞り込み（日付・写真・属性・関与・状態）はすべての図と表に効く。絞り込んだ結果と、共起の線の一覧は CSV で保存できる
- 色の見方：マゼンタ＝その図で注目してほしいところ／グレー＝その他・比較相手／青・淡青・黄・赤（◎○△×）＝気持ちの向き／青緑・オレンジ（↑↓）＝多い・少ない／紫の濃淡＝段階
- 名前とひとことが表示されるので、共有・印刷に注意。パスワードは保存せず、ログインはブラウザのタブを閉じるまで

## 設計の考え方（2026/11/13 改良会議）

デザイナー・アプリ開発者・PM・ビジネスアナリスト・データサイエンティスト・コンサルタント・エンジニア・ユーザー（お年寄り）・ユーザー（批判的）の視点で v2.2 を見直した結果です。

1. 聞いてから聞く：ひとことを受けて返し、ひとことに書かれた気持ち・人は先に選んでおく。問いの言い方もひとことの話題を使う（v2 は、ひとことを「見たもの」と決めつけ、次の問い「なにをしていましたか？」とつながっていなかった）
2. 問いは 4 つ（だれと → どこが → 気持ち → このあと）。「なにをしていた？」は AI が読み取る。点数は聞かず、気持ちから向きを計算
3. 投稿がどう育つかを常に見せる（深掘りのゴールが見える）。見本はひとことのあとに「ほかの人の例」として。ラベルは出さない
4. AI は 2 回・待たせない（ひとことの直後に裏でヒント、最後に投稿文）
5. 本人が選べる：AI の文／自分の言葉の文。ハッシュタグは本人が決める
6. お年寄りにやさしく：大きな文字とボタン、「#」なし、「次へ」「とばす」はボタン、文字を大きくするメニュー、話して入力の案内
7. いつでも終われる、何に使うかを伝える
8. 分析は後工程まで：記録を分析しやすい列に整理し、分析画面をつくる。読み出しは管理者パスワードだけ
9. 効果測定の注意：コーチの関与（ひとことのみ／選択あり／AI仕上げ）、見本を見たか、選択肢の表示順を記録し、分けて比べられるようにする
